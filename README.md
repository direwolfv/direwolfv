# direwolfv

macOS tools I build for myself and publish.

## Projects

- **[greythr-swipe](https://github.com/direwolfv/greythr-swipe)**: greytHR auto sign in / sign out for macOS.
  A menu bar app with a launchd timer, and credentials stay in the Keychain.
  `brew install direwolfv/tap/greythr-swipe`
- **[homebrew-tap](https://github.com/direwolfv/homebrew-tap)**: Homebrew tap for my macOS apps.
- **[water-reminder](https://github.com/direwolfv/water-reminder)**: an hourly "Drink water" notification from a launchd agent, with no app to keep open.
